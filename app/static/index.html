BookingPilot ↗

From a customer message to an appointment and confirmation draft. A safe, local demonstration of an AI-assisted booking workflow.

1. Try a customer request

The free rule-based parser expects an ISO date and time. Add an OpenAI key for optional LLM parsing.

How it works

The n8n version uses the same backend via an HTTP workflow.

① Webhook accepts the customer message.

② Extract recognizes contact and appointment fields.

③ Route checks whether the request is complete.

④ Reserve books one free slot in SQLite.

⑤ Confirm returns a response and creates an unsent email draft.

Demo safety: This app does not send emails or make phone calls. Bookings are stored locally. Do not expose the demo publicly without authentication.
